Моделирование

Клиент едет без приборов. Мы показываем ему это — его же словами.

Бесплатный отчёт после созвона для холодных клиентов; для входящих позже станет платным. Созвон закладывает мысль, отчёт её добивает. Без кликбейта: у каждой цифры подписан источник.

Рамка — у всех одинаковая

  1. Шапка: компания, дата, «составлено из ваших ответов».
  2. Математика бизнеса: множители с пометками «знаете точно / примерно / не знаете».
  3. Путь клиента с отметками модулей.
  4. 2–3 модуля из библиотеки: ваши слова → оценка по вашим словам → что увидите после настройки.
  5. Приборная панель со стрелками на нуле.
  6. Слова клиента о выгоде и пакет по размеру.

Связь с брифом

S ситуация→ путь клиента
P проблема→ цитаты в модулях
I последствия→ оценка, с которой клиент согласился
N выгода→ финал отчёта

Не пугаем суммами — показываем, сколько клиент не видит.
