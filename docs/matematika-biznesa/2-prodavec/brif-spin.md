# Бриф «Моделирование» (v3 — модульный)

Созвон закладывает мысль, отчёт «Моделирование» её добивает.
Бриф собирается как КП — из блоков: **ядро** (всем одинаково) → **поиск боли** (по этапам) → **глубина** (по 2–3 модулям из библиотеки).
Библиотека модулей: `3-direktor/moduli-poter.md`.

**Правила разговора**
- Это разговор, а не анкета: тема → где болит → во что обходится → следующая тема (SPIN спрятан внутри).
- Фразы клиента о проблеме и о выгоде записываем **дословно** — они попадут в отчёт.
- Цифры клиент называет сам; если не знает — записываем «не знает» (это тоже вывод).

---

## Шаг 1. Ядро — всем (5 минут)
Даёт рамку отчёта: путь клиента и формулу.
1. Чем занимаетесь, что продаёте, кто ваш клиент?
2. Сколько человек работает с клиентами?
3. Откуда приходят клиенты? Сколько обращений в месяц, примерно?
4. Какой средний чек? Из 10 обратившихся сколько покупают?
5. Расскажите путь клиента: от первого сообщения до оплаты — какие шаги?

Записать: этапы пути (для схемы), цифры с пометкой «точно / примерно / не знает».

## Шаг 2. Поиск боли — по этапам (5–7 минут)
По одному открытому вопросу на этап. Слушаем **маркерные фразы** — по ним понимаем, какой модуль болит.

| Этап | Открытый вопрос | Слышим… | → Модуль |
|---|---|---|---|
| Привлечение | «Какой канал для вас главный и почему?» | «не знаю точно», «реклама вроде работает» | М1 |
| | | «с сайта иногда не доходит» | М2 |
| | | «отзывы — если вспомним», «сарафан сам по себе» | М3, М4 |
| Первый контакт | «Что происходит, когда приходит новая заявка?» | «отвечаем, когда получится», «вечером никто» | М5 |
| | | «не дозвонились — перезвонят» | М6 |
| | | «кто первый увидел» | М7 |
| | | «записались и не пришли» | М8 |
| Продажа | «Где чаще всего клиент "отваливается"?» | «забыли перезвонить» | М9 |
| | | «отправили расчёт — молчит» | М10 |
| | | «сказал "подумаю"» | М11 |
| | | «отказался и отказался» | М12 |
| | | «у одного продаёт, у другого нет» | М13 |
| | | «долго», «месяц-два» | М14 |
| | | «КП/договор вручную» | М15 |
| | | «доп не предлагаем», «скидки по ситуации» | М16 |
| Оплата и исполнение | «Что происходит после того, как клиент согласился?» | «доплату выбиваем» | М17 |
| | | «передаём на словах», «сроки срываются» | М18 |
| После продажи | «Что происходит с клиентом после покупки?» | «купили и пропали» | М19 |
| | | «отказался — значит, всё» | М20 |
| | | «база в телефоне», «дубли» | М21 |
| Управление | «Как вы понимаете, что в продажах всё нормально?» | «спрашиваю менеджера» | М22 |
| | | «пишут со своих телефонов» | М23 |
| | | «план? не знаю» | М24 |
| | | «в сезон завал» | М25 |

Отметить 2–3 самых «горячих» модуля — где клиент говорил эмоциональнее всего или повторялся.

## Шаг 3. Глубина — по 2–3 модулям (5–10 минут)
Для каждого выбранного модуля из библиотеки:
1. **Скрининг-вопрос модуля** (из библиотеки) — подтвердить боль.
2. «Как часто это бывает?» / «Сколько таких в месяц?» — цифра для оценки.
3. **Последствия:** «Если прикинуть [шаблон оценки модуля] — получается около ___. Похоже на правду?» Записать, согласился ли.
4. Записать дословную фразу клиента.

## Шаг 4. Выгода — всем (2 минуты)
1. «Если бы это было решено — что бы изменилось лично для вас?» → **дословно**.
2. «Что будет хорошим результатом через месяц?»
3. «Когда хотите, чтобы заработало?»

**Завершение:** «Спасибо! В течение суток пришлю схему вашего процесса и что мы увидели».

---

## Шаг 5. Техническая часть — только перед КП (тёплые)
- Была ли раньше CRM? Какая, почему ушли?
- Телефония: какая, сколько номеров?
- Мессенджеры и соцсети: какие, сколько аккаунтов?
- Сайт: на чём, какие формы? Нужны ли документы, оплаты, 1С, таблицы?
- Клиентская база: есть ли, в каком виде, сколько записей?

## Что получается на выходе созвона (карточка для отчёта)
- Этапы пути клиента.
- Цифры ядра с пометками «точно / примерно / не знает».
- 2–3 модуля: дословная фраза + цифра + согласие клиента с оценкой.
- Фраза клиента о выгоде.
