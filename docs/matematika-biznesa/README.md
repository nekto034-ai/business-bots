## Статус (04.10.2026)

### Сделано
- Позиционирование: середина рынка, формула «Математика бизнеса», рост вширь, план по этапам.
- Сопровождение: 3 уровня, оплата периодом с лицензией, время реакции, почасовые ставки, «Ускорение» — в трёх взглядах (клиент / продавец / директор).
- Внедрение: процесс «как есть → как будет», разбор архива КП, черновик пакетов Старт / Бизнес / Команда, категории интеграций.
- Продажи: библиотека 25 модулей потерь, модульный бриф (ядро → поиск боли → глубина → выгода), макет «Моделирования», концепция «было → стало» и метрики.

### Предстоит (по приоритету для интенсива окт–дек)
1. Утвердить пакеты внедрения и единый прайс доп. услуг → три взгляда.
2. Шаблон КП из блоков (модули → строки КП), затем красивое оформление.
3. Проверить бриф + «Моделирование» на 3–5 реальных клиентах (вручную).
4. Поиск клиентов: кому звоним (сегменты, базы), первое сообщение/звонок, сайт и реклама.
5. Договор-оферта (шаблон Артёма) и регламент оплаты 50/50.
6. Своя воронка продаж в amoCRM Артёма по этапам процесса.
7. Кейсы из 8 отзывов в формате «было → сделали → стало».
Потом: бонусы сопровождения ярче, ИИ-помощник, масштабирование «Моделирования», ИП и найм.
