## Продажа в холодную — правило бесплатной работы
- Бесплатно: созвон по брифу (20–30 мин) + КП по шаблону с простой схемой процесса клиента (до ~1 ч работы).
- Прототип в amoCRM клиента — только после предоплаты 50% (это уже начало внедрения).
- Платный «Проект» (карта процессов + прототип) — только для тёплых клиентов и сложных задач.

## Договор и ЭДО
- Самозанятый может работать по ЭДО (операторы: Контур, Такском и др.), нужна электронная подпись физлица. Проверить вариант с Госключом (Госуслуги).
- Минимум: договор-оферта (принимается оплатой) — фиксирует состав работ. Шаблон есть у Артёма.

## Отчёт «было → стало» — как устроен
1. На брифе фиксируем точку А (со слов клиента): заявок в месяц, скорость ответа, сколько теряется, конверсия, средний чек.
2. Если CRM уже есть — берём цифры из неё.
3. После внедрения CRM считает те же метрики сама.
4. Через месяц — сравнение А и Б. Позже — автоматически из amoCRM по API.

## Портрет клиента
- Целевой: не хочет и не будет разбираться сам, хочет «чтобы сделали» и работало.
- «Умный» клиент, готовый делать сам: не наш клиент на внедрение, но возможен как клиент на консультации, «Моделирование» или проверку его настроек (почасово).
