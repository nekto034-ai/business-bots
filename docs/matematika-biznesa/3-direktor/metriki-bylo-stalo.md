# Метрики «было → стало» (черновик v1)

## Принцип
Фиксируем «точку А» на брифе → после внедрения CRM считает те же метрики → через месяц сравнение.
Метрики честные, но выбраны те, что после внедрения стабильно улучшаются.

## Базовый набор (5 метрик)
| # | Метрика | Точка А (откуда) | Точка Б (откуда) |
|---|---|---|---|
| 1 | Заявок в месяц (по каналам) | слова клиента / его CRM | amoCRM: новые сделки по источникам |
| 2 | Скорость первого ответа | слова клиента | amoCRM: время до первого ответа/звонка |
| 3 | Доля потерянных заявок | слова клиента (или оценка 10%) | amoCRM: сделки без ответа / без задачи |
| 4 | Конверсия заявка → продажа | слова клиента | amoCRM: успешные / все |
| 5 | Средний чек | слова клиента | amoCRM: бюджет успешных сделок |

## Дополнительные (для «Развития» и расширенного отчёта)
- Доля повторных продаж.
- Доля сделок с задачей (контроль менеджеров).
- Время руководителя на контроль (со слов, до/после).

## Потери в рублях
Потери/мес = Заявки × Доля потерянных × Конверсия × Средний чек.
В отчёте «было → стало»: «потери были ~54 000 ₽/мес → стали ~9 000 ₽/мес».

## Где используется
1. «Моделирование» — потери в рублях как аргумент.
2. КП — обоснование цены.
3. Отчёт через месяц — доказательство результата, повод продлить сопровождение и попросить отзыв.
4. Кейсы для сайта.
5. Позже — автоматический отчёт из amoCRM по API.
