# Библиотека модулей «где теряются деньги» — кубик Рубика (v2)

Принцип как у КП Артёма: готовые блоки, для каждого клиента берём нужные и подставляем его данные.
«Моделирование» = постоянная рамка + 2–3 модуля, которые болят у этого клиента.
Модули сгруппированы по этапам пути клиента — так их проще искать на созвоне.

## Формула
**Деньги = Обращения × Конверсия × Средний чек × Повторные покупки (+ рекомендации), за время цикла сделки**
Каждый модуль бьёт по одному из множителей: **О** — обращения, **К** — конверсия, **Ч** — чек, **П** — повторные, **В** — время, **Д** — деньги (продано, но не получено), **Р** — риск/управляемость.

## Постоянная рамка «Моделирования»
1. Шапка. 2. Путь клиента (схема). 3. Формула: что видно, что нет. 4. **2–3 модуля**. 5. Приборная панель (метрики модулей). 6. Слова клиента о выгоде + предложение.

## Шаблоны оценки потерь (подставляем в модуль)
| Шаблон | Формула | Модули |
|---|---|---|
| Потерянные заявки | Заявки × доля потерянных × конверсия × чек | М2, М5, М6, М7, М9 |
| Невозвращённые | Число «зависших» × доля, которую можно вернуть × конверсия × чек | М8, М10, М11, М20 |
| Недополученный чек | Продаж в месяц × рост чека | М16 |
| Повторные | Клиентов в базе × доля, которые могли бы купить снова × чек | М19 |
| Деньги в долгах | Сумма неоплаченного | М17 |
| Время | Часы в неделю × стоимость часа | М15, М22 |
| Невидимые деньги | Рекламный бюджет каналов без продаж | М1 |
| Риск | Без суммы: «что будет, если…» | М18, М21, М23, М24, М25 |

Правило: в «Моделирование» идёт **одна** оценка на модуль, всегда с пометкой «оценка по вашим словам».
