Зачем: одна цена на одну услугу для всех клиентов. Из этих строк собирается любое КП.
Цены — за работу. Лицензии amoCRM и подписки виджетов — отдельно (там комиссия 50% и 10–40%).
Колонка «было» — цены из архива КП 2024–2025.
