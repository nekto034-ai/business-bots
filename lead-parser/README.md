# Парсер лидов (2ГИС + hh.ru)

Собирает небольшие компании, которым могут быть нужны услуги интегратора
(CRM, автоматизация продаж), и складывает их в Excel. Список отсортирован
по баллу, и для каждой компании написано, **почему она подходит**: это готовый
повод для звонка.

## Что делает, по шагам

1. **Ищет в 2ГИС** по нишам и городам из `config.toml`, например «корпоративные подарки, Казань».
2. **Отсеивает** неподходящих: компании с филиалами, с большим числом отзывов
   (уже раскручены), без телефона и федеральные бренды из стоп-листа. У 2ГИС
   офисы МТС, Сбера и т. п. часто числятся отдельными компаниями «без филиалов».
3. **Открывает карточку** и берёт телефоны, сайт, email, соцсети и мессенджеры,
   а также дату появления компании в 2ГИС.
4. **Проверяет сайт**: есть ли он вообще, открывается ли, есть ли https, подстроен ли
   под телефон, есть ли форма заявки, не застрял ли «©» в подвале на 2019 годе.
5. **Проверяет hh.ru**: ищет ли компания сейчас менеджера по продажам. Если да, у неё
   точно есть продажи. Работодателя сверяем строго: то же название, тот же город,
   а если у обоих указан сайт, то и тот же сайт. Если сверить по сайту нельзя,
   в таблице так и написано: «похоже, проверь». Если у компании на hh больше
   30 вакансий, это крупная компания, и она отсеивается.
6. **Считает баллы** и сохраняет `output/leads_<дата>.xlsx` (и `.json` для будущей
   загрузки в CRM).

Компании, которые уже попали в прошлые выгрузки, повторно не показываются
(список хранится в `data/exported.json`).

## Как запустить

```bash
pip install -r requirements.txt
python run.py              # сколько собрать — из config.toml (target_leads)
python run.py --target 20  # или указать прямо здесь
```

## Как настроить под себя

Всё настраивается в `config.toml`, код трогать не нужно:
- `[[cities]]` — города (запасные уже вписаны, их нужно просто раскомментировать);
- `[[niches]]` — что искать, B2B или B2C, сезонная ли ниша;
- `[filters]` — жёсткие фильтры (филиалы, максимум отзывов, стоп-лист брендов);
- `[scoring]` — сколько баллов даёт каждый признак.

## Ограничения, о которых стоит знать

- **Размер компании** (1–15 человек) на картах не указан. Его оцениваем косвенно:
  нет филиалов и мало отзывов.
- **Авито не используется**: он сразу блокирует роботов (ответ 429).
- **Сайты с защитой от роботов** парсер не может оценить. Такие помечаются как
  «не удалось проверить», и за них баллы не начисляются. То же самое с сайтами,
  которые не ответили вовремя: многие российские сайты не пускают зарубежные
  адреса, а облачная сессия Claude работает не из России. На российском сервере
  таких случаев будет меньше.
- **2ГИС может поменять устройство сайта**, и тогда сбор перестанет работать.
  Парсер в этом случае остановится с понятной ошибкой и сохранит то, что успел собрать.
- **Темп специально медленный** (пауза 2.5–5 секунд между запросами), чтобы не
  получить блокировку. 60 компаний собираются примерно за 30–40 минут.
